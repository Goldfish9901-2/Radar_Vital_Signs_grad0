            <p></p>

            <p>

                
                    
                        <p>You can choose either to export your training file as a GPX, TCX, CSV or FIT file, or to zip the files for faster download. In case you have a slow internet connection, we recommend you choose the compressed zip file for bigger training files to speed up the export.</p><p>You can export the route of a training session in GPX and FIT format and other training data - such as heart rate, calorie and cadence data - in TCX format, CSV format, or FIT format. These formats are widely supported in 3rd party services, such as Training Peaks and Strava. Export of multisport training sessions is available in GPX, FIT and TCX file formats.</p><ol><li>Go to <strong>Diary</strong>.</li><li>Click a training session to open it.</li><li>Click <strong>Export </strong>drop-down menu on the top right side of the page.</li><li>Choose whether you want to export a <strong>TCX</strong> file, <strong>CSV</strong> file, <strong>FIT</strong> file, <strong>GPX</strong> file or one of the files as a <strong>zip package</strong>. Exporting the file as a zip package makes downloading faster.</li></ol><img src="/img/cms/9535c3b350ec8d1babaf822f3276e5941634fb42-235x414-default.webp" alt="" class="block-image"  style="width: 150px;" /><p>The selected file is saved into your computer&#x27;s default downloads folder. For example, in Windows the folder is: C:\Users\username\Downloads.</p><p>
              <div class="info-box  "><p>You need to extract the ZIP file first, before you import GPX and TCX files into 3rd party services.</p></div>
            </p><p>Different programs and sites handle the data differently, some use it as it is, while others recalculate and/or filter it based on their own algorithms. This is why the data exported from Polar Flow may appear slightly different in a 3rd party web service.</p>
