# 同步真实数据：一次冻结的 CW 相位/FFT 小型实验

本轮停止旧六条FTU记录上的合成校准，转向公开GUARDIAN临床数据（Scientific Data 7:291，2020；Figshare 12186516.v2）。先于任何新受试者信号数组读取冻结protocol.json及执行源码。只按首个官方分片的ID哈希选择GDN0002、GDN0007、GDN0006，取Resting与首个Valsalva恢复段，不替换失败记录，其余受试者不访问。

官方采用专门Gold-code同步通道校正采样率比和起始偏移，不通过HR匹配同步。但发布数据已删除同步序列，尚无逐记录剩余时钟误差的可核验数值界。本实验明确保留此限制；固定±0.5秒仅作敏感性分析，不是测得的误差界。自动ECG R峰也需独立质量审查，双导联一致不等于临床裁定。

新仪器是CW I/Q，并非ADC/RDA数据。固定一个初始30秒椭圆校准适配器、P2相位增量和25.6秒FFT读数；这个适配器不等同于官方加密MATLAB elreko实现。没有Range/Beam选择或HR引导选峰。静息评分[30,210)秒，恢复评分为首次操作结束后[30,210)秒，依据独立按钮标记；不拼接记录，不评分主动操作/体位变化。

参考定义为完整窗口内分段60/RR的时间平均，锚点为窗口中心。固定NeuroKit2版本和R峰方法，异常RR和缺失支持使窗口无效，不编辑搏动、不填零或外推。保存两导联原始评分段ECG及RR。报告原始MAE、相邻窗变化RMSE、同一评分区间的去趋势残差误差，比较离线个体常数与时间趋势oracle；oracle不作为可部署基线。按受试者汇总，不把重叠窗口当独立样本，不设通过记录数配额。

原始数据本地缺失，故按AGENTS.md在私有Kaggle CPU运行。官方ZIP中央目录可用HTTP Range读取，仅获取6个指定MAT成员（357,437,510字节），检查官方成员CRC及新增SHA256。原始公开文件不上传GitHub；紧凑诊断与协议、来源哈希、执行时间归档。若采集/接口/校准/参考门控失败，按失败原因报告，不能据此断言雷达没有心跳信息。

本轮是新受试者上的一次预先冻结试验，但只有3名受试者；时钟误差及自动参考未裁定之前，不能声称细节动态性能已独立确证。不得查看结果后改阈值、读数、区间或替换受试者。
